# Glossary

## Command candidate

The shell command generated by `pi` from a natural-language request.

## Confirmation menu

The interactive `shask` prompt that lets the user execute, revise, describe, copy,
or quit after a command candidate is generated.

## Current-shell execution

Execution through the sourced zsh function, where commands such as `cd` can affect
the user's active shell session.

## Child-shell execution

Execution through `bin/shask`, where generated commands run in a subprocess and
cannot change the parent shell's directory, environment, aliases, or options.

## Generation prompt

The instruction block sent to `pi` that defines the target OS, shell, context,
and output rules.

## Shell context

Small environment summary included in the generation prompt. By default this is
macOS version, zsh version, and current directory. Limited git status is opt-in.

## zle widget

A zsh line-editor function. This project binds one to `Alt+E` so the current
buffer can be replaced with a generated command before execution.
